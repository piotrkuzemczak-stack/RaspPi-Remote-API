# RaspPi-Remote Lite (Garmin IQ)

A script for the secure installation of an API to control your Raspberry Pi directly from a Garmin watch (via Tailscale).

## Installation
Run the following command in your Raspberry Pi terminal:

```bash
curl -sSL https://raw.githubusercontent.com/piotrkuzemczak-stack/RaspPi-Remote-API/main/garmin-api-install.sh | sudo bash
